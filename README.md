# 勇氣城堡 V3

完成一題，砌一塊積木；勇敢改正，城堡就多一盞燈。給小朋友記錄做題與改正錯誤的鼓勵工具。

網站：https://porscheyeung.github.io/Courage-Castle/
舊版 V2.3：https://porscheyeung.github.io/Courage-Castle/v2.3.html

## 玩法
- **完成一題**：加一塊積木。城堡藍圖用虛線預告完整城堡，「＋」是下一塊的位置。
- **勇敢改正**：點亮一塊積木（可先點選想點亮的積木），之後可寫下「學到甚麼」小紙條。
- **勇氣燈串**：每改正 8 次，一串燈掛到城堡上。
- **夜景**：亮著的積木變成窗，12 位窗後小住客按改正次序搬進來。
- **勇氣日記**：重溫及列印小紙條；點亮著的積木也能看。
- **提燈小騎士**：點牠巡邏亮著的窗。
- **建造回放**、每日及七天紀錄、連續天數。
- 完成原定目標後可繼續擴建花園、村莊、守護隊、慶典（每 20 題一區），並可下載紀念圖及備份。

## 檔案
- `index.html`、`style.css`、`app.js`：V3 介面。
- `engine.js`：規則（排位、存檔讀取、燈串、住客、統計），可在 Node 測試。
- `v2.3.html`：原 V2.3，原封不動保留。`index_v2.html`：更早期版本。
- `tests/`：`npm test`（Node 規則測試＋Playwright 瀏覽器測試，含 iPhone WebKit 版面）。

純靜態網頁，資料只存在該瀏覽器的 localStorage，不上傳。
