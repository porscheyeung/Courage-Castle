# 勇氣城堡 V3

完成一題，砌一塊積木；勇敢改正，城堡就多一盞燈。給小朋友記錄做題與改正錯誤的鼓勵工具。

網站：https://porscheyeung.github.io/Courage-Castle/
舊版 V2.3：https://porscheyeung.github.io/Courage-Castle/v2.3.html

## 玩法
- **完成一題**：加一塊積木。城堡藍圖用虛線預告完整城堡，「＋」是下一塊的位置。
- **勇敢改正**：點亮一塊積木（可先點選想點亮的積木），預設不用寫日記；想寫時按訊息欄的「寫日記」或點亮著的積木，寫下「學到甚麼」小紙條。
- **勇氣燈串**：每改正 8 次，一串燈掛到城堡上。
- **夜景**：亮著的積木變成窗，12 位窗後小住客按改正次序搬進來。
- **勇氣日記**：重溫及列印小紙條；點亮著的積木也能看。
- **提燈小騎士**：點牠巡邏亮著的窗。
- **建造回放**、每日及七天紀錄、連續天數。
- 完成原定目標後可繼續擴建花園、村莊、守護隊、慶典（每 20 題一區），並可下載紀念圖及備份。

## 勇氣寶庫（獎賞抽獎）
網址：`reward.html`（城堡右上角 🎁 進入）。
- **抽獎券**：每完成一座勇氣城堡（原定目標全部完成），打開寶庫會自動得到 1 張；同一座城堡只發一次。家長可在家長區開啟「每擴建 20 塊再送 1 張」，或手動送出／收回（要寫原因）。
- **開寶箱**：點寶箱 3 次 → 寶箱爆開、卡牌旋轉飛出 → 點卡牌翻開。第二下點擊時寶箱光芒會轉成稀有度顏色（普通藍、稀有紫、史詩金、傳說彩虹）。可按「略過」或在家長設定關閉動畫。
- **獎賞卡**：完整獎賞抽中即放入寶物袋；碎片獎賞（2–6 片）要集齊才自動合成。未集齊時較大機會抽到未有的碎片。
- **寶物袋**：等家長兌現的獎賞、碎片進度、已兌現紀錄。**圖鑑**：全部獎賞及機率，未抽過的保持神秘。**紀錄**：抽獎券、抽獎、合成、兌現全記錄。
- **家長區**（4–8 位數字密碼，關閉即重新上鎖）：新增／修改獎賞（名稱、說明、8 款插畫、稀有度、完整或碎片、權重、數量）、送券、兌現、碎片修正、備份及還原。
- 資料存在 `courage-reward-v1`，與城堡同一部機同一個瀏覽器才可自動發券；寶庫只讀城堡存檔，不會改動。

## 檔案
- `index.html`、`style.css`、`app.js`：V3 介面。
- `engine.js`：規則（排位、存檔讀取、燈串、住客、統計），可在 Node 測試。
- `v2.3.html`：原 V2.3，原封不動保留。`index_v2.html`：更早期版本。
- `reward.html`、`reward/`：勇氣寶庫（`reward-engine.js` 規則、`reward-app.js` 介面、`reward.css`、`art/` 卡牌插畫）。
- `tests/`：`npm test`（Node 規則測試＋Playwright 瀏覽器測試，含 iPhone WebKit 版面）。

純靜態網頁，資料只存在該瀏覽器的 localStorage，不上傳。
